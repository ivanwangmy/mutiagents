# 第 0 轮：AI 智播课堂产品需求与技术架构设计

本轮暂时不编写业务代码。

你需要根据项目总控规范，为 AI 智播课堂制定一套可以真正落地的产品需求和技术架构方案。

## 一、产品需求文档

明确：
1. 产品定位。
2. 核心用户场景。
3. 第一阶段功能范围。
4. 明确暂缓的功能。
5. 三个 Agent 的角色定位。
6. 单 Agent、双 Agent、三 Agent 互动模式。
7. 用户提问到最终讨论结束的完整流程。
8. Agent 自主决策的具体要求。
9. 前端界面和交互要求。
10. 未来扩展方向。

## 二、技术架构设计

设计以下模块：

- Frontend
- Backend API
- Agent Runtime
- Agent Graph
- Agent Message Bus
- Agent Skills
- Tool Registry
- Memory System
- Model Provider
- Event Streaming
- Database

明确模块职责、数据流和依赖关系。

重点说明：
1. LangGraph 如何承载多个独立 Agent。
2. Agent 如何进行消息交互。
3. 如何限制参与者范围。
4. 如何避免固定轮流发言。
5. 如何实现独立长期记忆。
6. 如何从后端向前端推送真实事件。
7. 如何支持未来课堂资料和 PPT 能力。

不要过度设计，也不要将所有逻辑塞进一个 Agent 或一个 Graph 节点。

## 三、数据库设计

初步设计：
- Agent
- AgentConfig
- AgentSkill
- AgentToolPermission
- Conversation
- ConversationParticipant
- Message
- AgentMemory
- ToolCall
- TaskExecution
- TaskEvent
- AgentExperience
- UserFeedback

区分业务数据与 LangGraph Checkpointer、Store 的持久化职责。

## 四、开发环境检查

规划：
- Python 版本。
- Node.js 版本。
- PostgreSQL。
- Docker。
- Git。
- 模型供应商及 API 配置。

明确开发所需环境和安装步骤。

## 五、输出要求

交付：
1. PRD.md
2. ARCHITECTURE.md
3. DATABASE_DESIGN.md
4. DEVELOPMENT_ROADMAP.md
5. TECH_STACK.md

每份文档都要具有实际开发指导意义。

本轮不要提前开发完整前后端，不要生成大量无实际作用的代码。

最后向我说明：产品如何运行、核心模块如何协作、下一轮如何开始。

# 第 3 轮：AI 智播课堂 Agent 角色视觉资产

本轮为三个固定 Agent 建立正式视觉形象。

## 一、视觉统一要求

三个角色必须采用统一的：
- 3D 卡通半写实插画风格。
- 人物头肩像构图。
- 光照与渲染风格。
- 画面质感。
- 背景处理方式。
- 人物比例。

人物之间必须明显不同，不能只是更换发型或颜色。

## 二、头像文件

正式资源目录：

frontend/public/agents/

文件名称：

alex.png
mia.png
ethan.png

要求：
- 正方形构图。
- 建议 1024×1024。
- 适合圆形和方形裁切。
- 人物面部位于视觉中心。
- 缩小到 48px 后依然能辨认。
- 背景简洁。
- 不出现文字、水印、Logo。
- 不要在图片中直接写 Agent 名称。

如果支持透明背景，可以额外保存透明背景版本。

## 三、角色资料

为每个 Agent 建立统一的前端展示配置：

- id
- name
- role
- short_description
- personality_tags
- avatar
- theme_color
- introduction

头像必须通过 Agent ID 统一关联。

禁止在各个组件中重复写头像路径。

## 四、界面应用

头像必须应用在：
1. Agent 选择卡片。
2. 课堂讨论消息。
3. Agent 状态面板。
4. Agent 资料展示。
5. 历史对话。
6. Agent 互动关系展示。

## 五、验收

1. 三张正式头像能够正常显示。
2. 所有界面使用同一套头像。
3. 头像尺寸和裁切统一。
4. 不存在随机头像。
5. 不存在字母占位头像冒充正式素材。

本轮不开发完整课堂前端，只完成素材管理和角色视觉配置。

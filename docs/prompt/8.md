# 第 8 轮：AI 智播课堂前端设计与开发

本轮正式开发用户界面。

必须以用户提供的参考截图作为主要视觉依据。

不要设计成普通 AI 聊天网站。

## 一、整体设计

采用桌面端优先的双栏式课堂界面。

页面由四个区域构成：

### 1. 顶部导航栏

包含：
- AI 智播课堂 Logo。
- 产品名称。
- 当前对话名称。
- 新建对话。
- 对话历史。
- 设置入口。

不增加课程管理和用户权限功能。

### 2. 左侧主区域：课堂讨论舞台

这是页面的核心视觉区域。

展示：
- 用户提问。
- Alex 的发言。
- Mia 的发言。
- Ethan 的发言。
- Agent 之间的回应。
- 提问、质疑和观点补充。
- 讨论结论。

消息必须具有明确的发送者身份。

每个 Agent 的消息显示：
- 正式头像。
- 名称。
- 角色标签。
- 消息正文。
- 必要的消息类型标识。

消息支持 Markdown。

数学公式必须正确渲染。

长消息需要合理排版，避免大段文字挤在一起。

### 3. 右侧 Agent 面板

展示三个 Agent 的头像和身份信息。

支持选择或取消选择参与者。

展示：
- Agent 简介。
- 人格标签。
- 当前状态。
- 当前参与情况。
- 工具调用状态。

用户可以点击 Agent 查看详细资料。

### 4. 底部提问输入区域

支持：
- 文本输入。
- 发送问题。
- 多行输入。
- Enter 发送。
- Shift+Enter 换行。
- 停止生成。
- 继续追问。

输入区需要清晰显示当前选择了哪些 Agent。

## 二、Agent 选择体验

提供三个独立的角色卡片。

点击即可选择或取消。

支持单 Agent、双 Agent、三 Agent。

至少选择一个 Agent 才能提交问题。

不能自动增加未选择的 Agent。

## 三、视觉规范

整体参考：
- 现代 SaaS 产品。
- 简洁、轻量。
- 白色、浅灰色背景。
- 低饱和紫色强调色。
- 统一圆角。
- 统一间距。
- 统一头像风格。

禁止：
- 大面积渐变。
- 过多卡片嵌套。
- 过大字号。
- 过多阴影。
- 复杂装饰动画。
- 不必要的空白。

## 四、响应式适配

桌面端：
保留双栏布局。

平板端：
适当压缩侧栏。

移动端：
Agent 选择和状态可以折叠为抽屉或顶部弹出面板。

## 五、组件结构

建议拆分：
- ClassroomLayout
- TopNavigation
- DiscussionPanel
- MessageList
- MessageBubble
- AgentAvatar
- AgentSelector
- AgentProfile
- AgentStatusPanel
- QuestionInput
- ConversationSidebar

不要把所有页面写进一个巨大组件。

## 六、验收

1. 页面结构完整。
2. 三个头像正常显示。
3. Agent 可以选择和取消。
4. 消息展示清晰。
5. 公式和 Markdown 正常显示。
6. 输入交互正常。
7. 桌面端布局符合参考图。
8. 页面不能使用模拟数据冒充后端功能。

本轮优先完成页面与接口对接准备，下一轮完善实时数据接入。

# 第 7 轮：Agent 记忆与上下文管理

本轮建立能够支持长期互动的记忆系统。

## 一、短期记忆

使用 LangGraph Checkpointer。

保存：
- 当前对话状态。
- 当前任务上下文。
- 已发送消息。
- Agent 当前执行状态。
- 工具调用状态。

支持中断和恢复。

## 二、长期记忆

使用 LangGraph Store 与 PostgreSQL。

每个 Agent 拥有独立 namespace。

示例：

agents/alex/memories/
agents/mia/memories/
agents/ethan/memories/

不得让 Agent 直接读取其他 Agent 的私人记忆。

## 三、记忆类型

区分：
- episodic_memory：经历记忆。
- semantic_memory：知识性记忆。
- preference_memory：交互偏好。
- relationship_memory：Agent 之间的互动经验。
- candidate_memory：待验证记忆。

## 四、记忆写入

不能把所有聊天消息都直接写进长期记忆。

需要：
1. 识别有长期价值的信息。
2. 提取候选记忆。
3. 去重。
4. 判断是否可靠。
5. 保存。
6. 后续按需检索。

## 五、记忆读取

Agent 生成回答前，根据当前问题检索相关记忆。

不能每次都无差别加载全部历史对话。

必须控制记忆长度和相关性。

## 六、管理与删除

为未来的记忆管理预留接口。

支持删除、失效和更新错误记忆。

## 七、验收

1. 同一对话能够保持上下文。
2. 不同对话能够按照设计恢复。
3. Alex 的私人记忆不会泄露给 Mia。
4. Agent 能够在后续对话中使用有效长期记忆。
5. 不相关记忆不会无条件进入上下文。

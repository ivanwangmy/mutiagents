# 第 5 轮：Agent Skills 与 Tool Registry

本轮为三个 Agent 建立真实的能力调用系统。

## 一、Skills 系统

建立统一 Skill 规范。

每个 Skill 必须包含：
- name
- description
- applicable_agents
- input_schema
- execution_logic
- output_schema
- permission
- examples

Skill 不是一段简单的 Prompt 描述，而是能够被 Agent Runtime 加载和使用的能力模块。

每个 Agent 只能加载自己拥有权限的 Skills。

## 二、Tool Registry

建立：
- ToolRegistry
- ToolDefinition
- ToolExecutor
- ToolPermissionManager
- ToolExecutionLog

必须完成真实的工具注册、权限验证、参数校验和执行。

## 三、第一批工具

1. Calculator：数学计算。
2. DateTime：日期和时间查询。
3. Python Sandbox：隔离 Python 代码执行。

Python Sandbox 必须运行在独立隔离执行环境中。

不得在 FastAPI 主进程中直接执行用户代码。

必须限制：
- CPU 时间。
- 内存。
- 执行时长。
- 文件访问。
- 网络访问。
- 并发数量。

## 四、真实 Tool Calling 流程

必须实现：

模型原生 Tool Call
→ 后端识别工具
→ 权限校验
→ 参数校验
→ 工具真实执行
→ 结果返回模型
→ Agent 继续分析
→ 输出最终回答。

工具执行失败时，必须将错误结果返回 Agent，允许 Agent 判断是否重试或解释失败。

## 五、验收

通过真实模型完成：
- 数学计算。
- 日期时间查询。
- Python 沙箱执行。

前端暂时可以使用接口测试工具验证。

不得用模型直接生成一个看似工具结果的文本来冒充执行成功。

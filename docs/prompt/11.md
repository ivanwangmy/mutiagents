# 第 11 轮：AI 智播课堂系统集成与最终验收

本轮对整个项目进行全面测试。

不得只检查页面是否能够打开。

## 一、单 Agent 测试

分别测试 Alex、Mia、Ethan。

验证：
- 人格稳定。
- 上下文连续。
- 真实模型调用。
- 流式输出。
- 工具权限正确。
- 记忆隔离。

## 二、双 Agent 测试

测试：
- Alex + Mia。
- Alex + Ethan。
- Mia + Ethan。

验证：
- 真实消息传递。
- 相互回应。
- 观点差异。
- 任务终止。
- 不存在未选 Agent。

## 三、三 Agent 测试

测试：
- 三 Agent 同时参与。
- 不同 Agent 自主决定发言。
- Agent 提出不同观点。
- Agent 能够相互质疑。
- 能够根据讨论结果结束任务。

## 四、工具测试

测试：
- 计算器。
- 日期时间。
- Python 沙箱。
- 工具权限。
- 工具执行错误处理。

## 五、记忆测试

测试：
- 对话短期记忆。
- 跨对话长期记忆。
- Agent 私人记忆隔离。
- 错误记忆删除。
- 经验使用。

## 六、前端测试

测试：
- 头像显示。
- Agent 选择。
- 消息展示。
- SSE 更新。
- 断线恢复。
- 数学公式。
- Markdown。
- 响应式布局。
- 停止生成。
- 任务失败展示。

## 七、安全测试

检查：
- API Key 泄漏。
- 工具权限绕过。
- Python 沙箱逃逸风险。
- 提示词注入。
- 越权访问其他 Agent 私人记忆。
- 异常输入。
- 超时与资源限制。

## 八、性能与成本

记录：
- 单 Agent 平均响应时间。
- 双 Agent 任务平均耗时。
- 三 Agent 任务平均耗时。
- 每次任务模型调用次数。
- Token 消耗。
- 工具调用次数。
- 失败率。

不要只追求更多轮次和更多消息。

# 第 9 轮：多 Agent 实时事件与课堂动态可视化

本轮将真实 Agent 运行过程接入前端。

## 一、SSE 事件体系

至少实现：

- conversation_started
- task_started
- agent_started
- agent_status_changed
- agent_message
- agent_question
- agent_challenge
- agent_handoff
- agent_tool_call
- tool_started
- tool_completed
- tool_failed
- agent_completed
- task_completed
- task_failed

## 二、事件结构

每个事件至少包含：
- event_id
- event_type
- conversation_id
- task_id
- agent_id
- timestamp
- payload

必须具有稳定的事件 ID。

## 三、前端状态展示

根据真实事件更新：
- Agent 正在处理。
- Agent 正在发言。
- Agent 正在调用工具。
- Agent 等待其他 Agent。
- Agent 已完成。
- Agent 执行失败。

不要让三个 Agent 同时永久显示为活跃。

## 四、消息展示

新消息到达时：
- 正确识别 Agent。
- 正确显示头像。
- 正确更新消息列表。
- 不重复插入消息。
- 保留历史消息顺序。

## 五、断线恢复

实现：
- SSE 自动重连。
- Last-Event-ID 或等效恢复机制。
- 历史事件补拉。
- 断线状态展示。
- 任务完成后关闭连接。

## 六、隐私与安全

禁止向前端传输模型内部思维链。

允许展示：
- Agent 公开消息。
- 行动摘要。
- 工具调用名称。
- 工具执行状态。
- 执行结果摘要。

## 七、验收

必须通过真实多 Agent 讨论验证：

前端能够实时显示 Agent 发言、相互回应和工具执行状态。

不能使用前端定时器模拟 Agent 工作。

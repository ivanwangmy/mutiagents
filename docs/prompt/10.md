# 第 10 轮：Agent 经验积累与成长系统

本轮让 Agent 能够从真实交互中提取经验，并在未来合理使用。

## 一、经验来源

- 任务执行结果。
- 工具执行成功或失败。
- 用户明确反馈。
- Agent 之间的有效协作。
- 已验证的知识修正。

## 二、候选经验

建立 AgentExperience。

字段包括：
- id
- agent_id
- experience_type
- content
- source_conversation_id
- confidence
- validation_status
- created_at
- updated_at

## 三、经验提取

任务结束后，根据实际交互提取候选经验。

不能将每次发言都转化为经验。

## 四、经验验证

候选经验需要判断：
- 是否真实。
- 是否可复用。
- 是否存在错误。
- 是否与已有经验重复。
- 是否可能造成错误行为。

只有通过验证的经验才可以成为长期经验。

## 五、未来使用

Agent 在后续任务中检索相关经验。

经验应该影响：
- 问题理解。
- 交流方式。
- 工具使用。
- 协作策略。

不能无条件注入所有历史经验。

## 六、安全约束

禁止 Agent 自动修改：
- 核心 System Prompt。
- 工具权限。
- 安全规则。
- 其他 Agent 的配置。

## 七、验收

通过多次真实对话验证：

Agent 能够从有效反馈中提取经验，在未来相似场景中合理使用，同时不产生错误记忆污染。

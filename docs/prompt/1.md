# 第 1 轮：AI 智播课堂全新项目初始化

现在开始正式编程。

必须在全新目录中建立项目，不允许迁移或复用旧 Demo 的代码。

项目目录：

multi-agent-classroom/

使用：
- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

建立基础目录结构：

frontend/
  src/
    components/
    pages/
    layouts/
    services/
    hooks/
    stores/
    types/
    assets/
    styles/
  public/
    agents/

暂时不开发复杂页面，只建立基础应用和必要的组件组织。

## 四、开发规范

建立：
- README.md
- .gitignore
- 前后端启动说明。
- 依赖版本记录。
- 基础日志配置。

前端和后端必须可以独立启动。

## 五、验收标准

1. 前端成功运行。
2. 后端成功运行。
3. 前端能够访问健康检查接口。
4. PostgreSQL 成功启动。
5. 数据库能够连接。
6. 环境变量配置正确。
7. 前后端不存在明显控制台错误。

完成后提供完整项目目录和运行命令。

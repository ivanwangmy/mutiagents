# AI 智播课堂 — 使用指南

本指南面向授课教师、教研人员与演示者，说明如何启动课堂、发起真实多 Agent 讨论、使用工具/记忆/经验，以及常见问题。

## 1. 系统是什么

AI 智播课堂是一个可真实运行的多智能体教学空间，固定三位参与者：

| Agent | 角色 | 风格 | 可用工具 |
| --- | --- | --- | --- |
| Alex | 教师 | 严谨的理论讲解者，擅长概念辨析与逻辑推导 | 计算器、日期时间、Python 沙箱、技能 |
| Mia | 助教 | 温和细致的拆解者，关注你是否真正理解 | 计算器、日期时间、技能（无 Python 沙箱） |
| Ethan | 学生 | 敢质疑的学生，用真实学习者视角检验结论 | 计算器、日期时间、Python 沙箱、技能 |

所有回答均来自真实模型调用；页面上的消息、状态、Token、工具调用都来自真实接口，不存在预设台词或假数据。

## 2. 启动与进入

最短路径（详细步骤见 [DEPLOYMENT_GUIDE.md](./DEPLOYMENT_GUIDE.md)）：

```powershell
# 1) 数据库
cd multi-agent-classroom
docker compose up -d postgres
docker compose up -d redis      # 多进程部署时需要；单进程可省略

# 2) 后端
cd backend
.\.venv\Scripts\python.exe run_server.py

# 3) 前端（另开终端）
cd ..\frontend
npm run dev
```

浏览器打开 **http://localhost:5173**。若后端未启动，页面会提示连接失败，不会显示假消息。

## 3. 第一次课堂

1. **选择参与者**：右侧 Agent 面板点击 Alex / Mia / Ethan，可多选，最多 3 位；顶部显示"x/3 已选择"。
2. **输入问题**：底部输入框输入内容，`Enter` 发送，`Shift + Enter` 换行。
3. **观察实时过程**：消息会自动出现，无需刷新；Agent 状态依次显示"正在思考 / 正在发言 / 等待"，完成后显示"已完成"。
4. **中途干预**：生成过程中可点击"停止生成"，输入框恢复可用；需要继续时可点击"继续生成"。
5. **切换对话**：左侧对话列表可新建或切换历史对话；刷新页面后历史消息仍保留。

推荐的首个问题（实测有效）：

> 为什么天空是蓝色的？ethan 请先质疑 alex 的解释，alex 再回应。

## 4. 如何用好三个 Agent

- **单 Agent 答疑**：只选一位。Alex 适合概念与推导，Mia 适合分步讲解，Ethan 适合暴露常见误解。
- **双 Agent 对话**：选两位，并明确要求互动，例如"mia 必须指出 alex 解释中的一个具体分歧点，alex 回应"。若不指定，模型可能只做公开补充，不产生定向消息。
- **三 Agent 讨论**：选三位，建议明确分工与顺序，例如：
  > 三位必须都发言，禁止使用 WAIT。顺序：alex 用一句话解释潮汐成因；mia 用一句话补充常见误解；ethan 用一句话提出质疑。每人只发言一次，发言后选择 FINISH。
- **提出质疑**：在问题中写"请用 CHALLENGE 指出……的具体分歧"，比"请讨论一下"更容易触发定向质疑。
- **控制篇幅**：要求"每人一句话""只发言一次"可显著降低 Token 消耗，也更容易在预算内完成。

## 5. 工具使用

- **计算器**：直接说"请用计算器计算 12345 × 6789"。真实返回 `83810205`。
- **日期时间**：说"请用日期时间工具告诉我现在几点，精确到分钟"。返回带时区的真实时间。
- **Python 沙箱**：说"请用 python_sandbox 计算 1 到 100 的和"。返回 `5050`；限制 5 秒、256MB。
- **权限**：Mia 没有 Python 沙箱权限，即使提示词要求也不会执行，也不会伪造结果。
- **错误处理**：如"用计算器计算 12 ÷ 0"，工具会返回 `ZeroDivisionError`，Agent 会如实说明，而不是编造结果。

## 6. 记忆与经验

- **对话内记忆**：同一对话中可追问"刚才那个例子再复述一遍"，Agent 会基于真实历史回答。
- **跨对话长期记忆**：任务结束后系统会提取长期记忆，例如"用户叫王明宇，偏好先用生活例子建立直觉"。新对话中提问"我叫什么名字"会检索并注入相关记忆。
  - 记忆抽取只保留有证据的信息；未记住的内容，Agent 会明确说"我的记忆里没有相关信息"，不会编造。
- **记忆隔离**：每位 Agent 的记忆相互独立，Mia 无法读取或修改 Alex 的私人记忆。
- **经验库**：顶部"经验库"可查看每个 Agent 的经验、验证状态（已验证/待验证/已驳回）、置信度与使用次数。
- **用户反馈**：助手消息支持点赞/点踩；负反馈会生成"知识修正"候选经验，经验证后可在后续相关问题中被复用。
- **删除记忆**：经验库/记忆接口支持删除错误记忆；删除后相关检索不再命中。

## 7. 公式与 Markdown

- 支持标准 Markdown：标题、列表、加粗、行内代码、代码块、表格。
- 支持 LaTeX：行内 `$x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}$`，块级 `$$...$$`，由 KaTeX 渲染为真实公式排版。
- 提示模型"请用 LaTeX 公式输出，不要用 Unicode 符号"，可获得最适合公式渲染的结果。

## 8. 状态说明

| 状态 | 含义 |
| --- | --- |
| 正在思考 | 该 Agent 已开始本轮模型调用 |
| 正在发言 | 内容已生成并写入消息 |
| 等待其他 Agent 发言 | 本轮不发言或已发言完毕 |
| 已完成 | 该 Agent 本轮参与结束 |
| 已停止 | 用户主动停止任务 |
| 失败 | 任务异常（当前版本会保留错误信息） |

## 9. 常见问题

**Q：为什么讨论还没说完就结束了？**
A：任务有 12,000 token、8 次模型调用、12 条消息、10 轮、120 秒上限。多 Agent 任务通常在 3—4 轮后触及 token 预算，属于保护机制，不是故障。可缩短问题、要求"每人一句话"，或由管理员调高 `TASK_TOKEN_BUDGET`。

**Q：为什么 Mia 不执行 Python 代码？**
A：Mia 的角色权限不包含 `python_sandbox`，这是设计约束。需要执行代码请选 Alex 或 Ethan。

**Q：为什么 Agent 没有回应另一个 Agent？**
A：取决于模型自主决策。要稳定触发定向质疑，请在问题中明确要求某位 Agent 质疑某位 Agent 的具体观点。

**Q：刷新页面会丢消息吗？**
A：不会。消息已落库，刷新后从接口恢复；实时事件通过 SSE 推送，断线重连会按 `Last-Event-ID` 补拉。

**Q：页面上有测试数据怎么办？**
A：本轮验收创建的对话标题均以 `【R11】` 或 `【R11-补充】` 开头，可在左侧对话列表删除。

**Q：能否公网访问？**
A：当前第一阶段没有登录鉴权，仅适合本地或受信内网。公网部署前必须增加认证、HTTPS、限流与访问控制。

## 10. 五分钟演示脚本（均实测通过）

1. 只选 Alex，问："请用通俗语言解释牛顿第三定律，并举两个生活中的例子。"（约 4 秒）
2. 选 Alex + Ethan，问："为什么天空是蓝色的？ethan 请先质疑 alex 的解释，alex 再回应。"（观察定向 `challenge`）
3. 选三位，问："三位必须都发言，禁止使用 WAIT。alex 一句话解释潮汐成因，mia 一句话补充常见误解，ethan 一句话提出质疑，发言后 FINISH。"
4. 点击"停止生成"，再刷新页面，确认历史消息保留。
5. 打开"经验库"，查看真实经验与验证状态；对一条回答点赞或点踩。

完成后可向观众说明：以上每个回答、工具结果、Token 与状态均来自真实后端，不是演示脚本。

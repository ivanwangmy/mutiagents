# AI 智播课堂 — 开发路线图

版本：v1.0
项目目录：`multi-agent-classroom/`

## 阶段划分

| 轮次 | 目标 | 主要交付 | 验收要点 |
|---|---|---|---|
| 0 | 需求与架构 | PRD / 架构 / 数据库 / 路线图 / 技术栈 | 文档可指导开发，模块边界清晰 |
| 1 | 项目初始化 | 前后端骨架、健康检查、.env 模板、DB 与迁移、docker-compose | 前后端可独立启动，健康检查通过，数据库可连接 |
| 2 | 三 Agent | 独立配置、Prompt、Skills、Registry、人格测试 | 同一问题三人观点/路径/风格有稳定差异 |
| 3 | 视觉资产 | 三张正式头像、统一角色资料、头像统一引用 | 全站同一套头像，无字母/随机头像 |
| 4 | 模型与单 Agent | DeepSeek 适配层、能力探测、对话 API、流式、Token 控制 | 三个 Agent 分别可真实多轮对话 |
| 5 | Skills 与工具 | Skill 规范、Tool Registry、权限、Calculator/DateTime/Python 沙箱 | 真实工具调用链路与失败回传 |
| 6 | 多 Agent 协作 | Message Bus、Discussion Manager、LangGraph 动态调度、预算 | 单/双/三 Agent 场景真实协作，无固定轮流 |
| 7 | 记忆 | Checkpointer 短期记忆、Store 长期记忆、隔离与删除 | 上下文连续、跨对话记忆、隔离可验证 |
| 8 | 前端界面 | 双栏课堂、消息/Markdown/公式、Agent 面板、输入区、响应式 | 页面完整、真实接口、无模拟数据 |
| 9 | 实时事件 | SSE 全事件、状态联动、断线重连与补拉 | 实时展示真实运行，无定时器模拟 |
| 10 | 经验系统 | 候选经验提取、验证、检索使用、安全约束 | 有效经验被复用，错误记忆不扩散 |
| 11 | 集成验收 | 全场景测试、安全/性能报告、用户与部署指南 | 全部结论有证据，明确已完成/未完成 |

## 关键里程碑

- M1（第 4 轮末）：真实模型可跑通单 Agent 流式对话，Token 统计可见。
- M2（第 6 轮末）：三 Agent 真实自主讨论，参与者边界生效。
- M3（第 9 轮末）：前端实时呈现真实事件，断线可恢复。
- M4（第 11 轮末）：完整系统可启动、可演示、可审计。

## 环境策略

- 开发与生产统一使用 Docker 中的 PostgreSQL 16：`docker compose up -d postgres`，连接串 `postgresql+psycopg://classroom:classroom_dev_password@127.0.0.1:5432/ai_classroom`，迁移用 `alembic upgrade head`。本机容器与迁移均已实测通过。
- 剩余未验证项：容器级 Python 沙箱（当前为独立子进程 + AST 白名单 + 资源限制），在最终报告中标注残余风险，不以其他结果冒充。

## 每轮工作流

1. 检查现有代码与运行状态。
2. 对齐本轮提示词，列出改动文件。
3. 实现并运行真实测试（含模型调用/接口调用）。
4. 输出验收结论：已完成 / 部分完成 / 未完成 / 未验证。
5. 用户确认后进入下一轮。

# AI 智播课堂 — 产品需求文档（PRD）

版本：v1.0（第一阶段）
日期：2026-11-23
状态：第 0 轮交付

## 1. 产品定位

AI 智播课堂是一个拟人化多智能体教学互动平台。用户向一个或多个具有独立人格、知识、记忆和行动能力的 Agent 提问，观察它们在同一课堂空间中真实地思考、发言、质疑、协作并给出结论。

它不是"一个模型套三个角色名"的聊天页，而是：每个 Agent 有独立 System Prompt、独立 Skills、独立工具权限、独立运行状态、独立长期记忆 namespace 和独立执行日志的多智能体系统。

## 2. 核心用户场景

1. 学习一个新概念：只选 Alex（教师），获得严谨的理论讲解与推理。
2. 概念听不懂：选择 Alex + Mia，Alex 讲原理，Mia 拆解并检查理解盲区。
3. 想看到争论与思辨：选择 Alex + Ethan，教师给出理论，学生提出质疑与替代假设。
4. 完整课堂：三 Agent 参与，围绕同一问题形成"讲解—追问—质疑—补充—结论"的真实讨论。
5. 需要计算/查时间/跑一段代码：Agent 通过真实工具调用完成，前端展示工具执行状态与结果摘要。

## 3. 第一阶段功能范围（必须实现）

- 三个固定 Agent：Alex（教师）、Mia（助教）、Ethan（学生），人格与能力真实差异化。
- 单 Agent / 任意双 Agent / 三 Agent 讨论，`selected_agent_ids` 为强制边界。
- 真实 Agent Message Bus：message / question / response / challenge / request_help / handoff / conclusion。
- Agent 自主决策：发言、追问、质疑、求助、调用工具、等待、结束，不固定轮流。
- 统一模型适配层，接入 DeepSeek（OpenAI 兼容接口），支持流式输出与原生 Tool Calling。
- Token 预算控制：单条输出上限、上下文裁剪、单任务模型调用次数/Token 预算/时长上限。
- Skills 与 Tool Registry：Calculator、DateTime、Python Sandbox（独立进程隔离执行）。
- 短期记忆（LangGraph Checkpointer）+ 长期记忆（LangGraph Store / 独立 namespace），支持中断恢复。
- SSE 实时事件：Agent 状态、发言、工具调用、任务完成/失败，带事件 ID 与断线补拉。
- 双栏课堂前端：讨论舞台 + Agent 状态面板 + 底部提问区，Markdown/公式渲染，响应式。
- 经验系统：任务结束后提取候选经验，验证后进入长期经验，可被后续任务检索。
- 全链路真实数据，禁止假消息、假工具调用、假状态动画。

## 4. 明确暂缓的功能

PPT 上传与解析、课程资料批量导入、课堂录制/语音/视频、作业与课程管理、学情分析、教师端/学生端权限系统、支付与社交、非必要登录。

架构上为"课程知识库 / PPT 理解 / 语音 / 教师控制"预留接口（知识检索服务、事件类型、工具注册扩展点）。

## 5. 三个 Agent 角色定位

| Agent | 身份 | 人格 | 核心能力 | 输出长度上限（默认） |
|---|---|---|---|---|
| Alex | 大学教师 | 专业、严谨、理性、有耐心 | 概念讲解、理论分析、逻辑推导、事实核验、教学引导、观点纠错 | 900 tokens |
| Mia | 课程助教 | 温和、细致、耐心、善沟通 | 问题拆解、知识整理、信息总结、学习辅助、盲区发现、内容补充 | 600 tokens |
| Ethan | 大学生 | 好奇、活跃、有主见、敢于质疑 | 主动探索、批判性提问、假设识别、跨学科联想、替代观点、学生视角检验 | 500 tokens |

拟人化要求落在：知识组织方式、判断习惯、提问方式、观点倾向、表达节奏、对其他 Agent 的持续认知、长期稳定人格，而非语气词和表情包。

## 6. 互动模式

- 单 Agent：只有被选中的 Agent 发言，其他 Agent 不出现、不被调度。
- 双 Agent：两人可相互回应、质疑、补充，也可由一人完成主要回答。
- 三 Agent：自主决定参与程度，允许有人少发言甚至不发言；讨论无必要时可结束。
- 约束：至少选择 1 个 Agent；未选中的 Agent 即使被消息 @ 也不得加入。

## 7. 完整用户流程

1. 用户新建对话，选择 1–3 个 Agent。
2. 输入问题并发送（Enter 发送，Shift+Enter 换行）。
3. 后端创建 Task，校验参与者，写入 Conversation/Message。
4. Discussion Manager 初始化任务预算（轮次、消息数、模型调用数、Token、时长）。
5. 调度器选择一个被允许发言的 Agent → Agent 读取公开讨论上下文 + 自己的相关记忆 → 决策（发言/追问/质疑/求助/工具/等待/结束）。
6. 模型流式生成；如有工具调用，执行真实工具并把结果回传给模型继续生成。
7. 每一步产生真实事件写入 TaskEvent，并通过 SSE 推送前端。
8. 达到终止条件（Agent 主动结束、预算耗尽、无新有效观点、任务完成）后结束任务。
9. 任务结束后提取候选经验，写入各自记忆，供后续任务检索。

## 8. Agent 自主决策要求

单次决策必须从以下行为中选择一个：RESPOND、ASK_USER、MESSAGE_AGENT、REQUEST_HELP、CHALLENGE、USE_TOOL、WAIT、FINISH。决策结果由模型基于上下文输出结构化 JSON，后端做校验与降级。

禁止：固定轮流发言、为热闹生成无意义消息、要求每个 Agent 每条消息都回应、用脚本模拟讨论。

## 9. 前端界面与交互要求

- 顶部导航：Logo、产品名、当前对话名、新建对话、历史对话、设置。
- 左主区（课堂讨论舞台）：用户提问与三个 Agent 的发言、消息类型标签、Markdown/公式、引用关系。
- 右侧 Agent 面板：头像、名称、角色、简介、人格标签、实时状态（思考中/发言中/调用工具/等待/完成/失败）、参与开关。
- 底部输入区：多行输入、当前参与者标签、发送、停止生成、继续追问。
- 视觉：白/浅灰底、低饱和紫色强调、统一圆角与间距、正式头像、桌面优先并适配平板/移动端（侧栏折叠）。
- 禁止：大面积渐变、重阴影、随机头像、字母占位头像、前端定时器模拟状态。

## 10. 未来扩展方向

课程知识库与 RAG 检索、PPT 解析、语音合成与课堂录制、教师控制台、学情分析、更多学科 Agent、多课堂并发与权限体系。所有扩展通过既有接口（知识检索服务、工具注册表、事件类型、Agent Registry）接入，不改动核心运行时。

## 11. 验收总标准

1. 真实模型调用，单/双/三 Agent 场景均可运行。
2. 未选 Agent 不出现；Agent 自主发言而非固定轮流。
3. 工具调用真实执行并回传结果；失败可解释。
4. 记忆隔离可验证；SSE 事件真实驱动前端。
5. Token/调用次数/时长预算生效，有可查询的用量记录。
6. 前端无假数据；关键测试有证据。
